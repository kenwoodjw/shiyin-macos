# 拾音 0.1.0 测试版 / Shiyin 0.1.0 beta

这是供测试的 macOS 安装包，**未经 Apple 公证**，使用临时签名。仅支持 **Apple Silicon、macOS 15 或更新版本**。已内置 yt-dlp、FFmpeg、ffprobe 和 Deno，无须另行安装。

This is an **unnotarized, ad hoc signed test build** for **Apple Silicon on macOS 15 or later**. yt-dlp, FFmpeg, ffprobe, and Deno are bundled.

## 安装 / Install

下载 `Shiyin-0.1.0-macos-arm64-LOCAL.dmg`，打开后将 `Shiyin.app` 拖入「应用程序」。若 macOS 拦截首次启动，先尝试打开一次，然后在「系统设置 → 隐私与安全性」点击「仍要打开」。也可以确认来源可信后执行：

Download the DMG, open it, and drag `Shiyin.app` to Applications. If macOS blocks launch, try opening once, then choose **System Settings → Privacy & Security → Open Anyway**. Alternatively, if you trust the download, run:

```bash
xattr -dr com.apple.quarantine "/Applications/Shiyin.app"
open "/Applications/Shiyin.app"
```

`xattr` 只移除下载隔离标记，不会为应用签名或公证。/ `xattr` only removes the download quarantine attribute; it does not sign or notarize the app.
